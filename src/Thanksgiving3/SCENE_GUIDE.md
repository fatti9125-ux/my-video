# Every President’s Thanksgiving Explained

The full sheets provide a visual index. Each stand-alone sprite is a transparent 512 × 512 PNG. **Poses** contains the illustrated characters and any props they hold. **Reusable_Bodies** contains four headless costume templates in three poses. **Head_Swaps** contains the illustrated heads in sheets 18–20. Scale and position each head above the costume collar in the edit.

**Tags** contains the procession and ceremony bird names, Kennedy’s placard, Rebecca’s collar text and the express crate label. Scale and overlay the appropriate tag for each scene.
